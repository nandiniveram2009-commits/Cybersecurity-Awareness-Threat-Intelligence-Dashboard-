🎓 Cybersecurity Awareness & Human Defense Modules

🎣 Phishing Awareness

Learn to identify deceptive emails, urgent pretexts, mismatched sender domains, and unexpected attachments.

  • Check sender header vs display name.
  • Verify requests for credentials via out-of-band channels.

🔑 Password & MFA Security

Utilize password managers, enforce passphrase complexity, and mandate phishing-resistant multi-factor authentication.

  • Never reuse organizational credentials.
  • Prefer hardware security keys or authenticator apps over SMS.

🚨 Ransomware Defense

Understand the lifecycle of ransomware attacks and how offline backups and least-privilege access mitigate impact.

📱 Mobile & Remote Security

Maintain secure remote work practices, avoid public untrusted Wi-Fi without VPNs, and keep operating systems updated.
